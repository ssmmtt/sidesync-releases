# SideSync

本地目录与远程（SFTP / FTP·FTPS / WebDAV / SMB）之间按文件大小、修改时间做对照，再按任务方向复制或删除。界面接近 GoodSync：左侧任务列表，中间是两侧路径和对照树。

支持本地路径、SFTP、FTP/FTPS、WebDAV、SMB。没有定时任务、云盘，也不做内容分块增量（大文件按流式传输，并可有条件断点续传）。

## 下载与运行

1. 打开 [Releases](https://github.com/ssmmtt/sidesync-releases/releases/latest)。
2. 按系统架构下载便携包：
   - 64 位：`sidesync-*-windows-x64-portable.zip`
   - 32 位：`sidesync-*-windows-x86-portable.zip`
3. 解压后进入 `SideSync` 文件夹，运行 `sidesync.exe`。
4. 任务配置会保存在程序旁边的 `data` 目录。升级时只替换主程序，这个目录会保留。

程序内也可点标题栏「更新」检查并安装新版本。

## 用法

1. 新建任务，左右两侧各选本地文件夹，或选 SFTP / FTP / WebDAV / SMB 并填连接信息与远端路径（FTP 可选 FTPS；SMB 需共享名，域可空；WebDAV 填完整 URL）。
2. 选同步方式：双向、镜像（左→右 / 右→左）、更新（左→右 / 右→左）。
3. 点「分析」。分析只读目录项的大小和修改时间，不读文件内容。
4. 用「全部 / 向右 / 向左 / 变更 / 待同步 / 冲突 / 其他」看结果。文件夹行显示该侧后代文件的总大小和最新修改时间；某一侧没有这个路径时显示「不存在」。
5. 右键一行可以改方向、标成删除、排除或包含。标成删除不会马上删文件，点「同步」才会执行。
6. 点「同步」。覆盖和删除前若打开了回收，原文件会移到同一侧的 `.sidesync-recycle`。远程传输写到 `.sidesync.part`，成功后再改名；断线会自动重试。

不同任务可以同时分析和同步。同一个任务不能开两份。取消只停当前选中的那一个任务，不能从中断处接着扫。

修改时间容差默认 2 秒。远程并行连接数是 1 到 8（主要用于 SFTP 扫描）。

两侧都改过时，默认标成冲突，等你指定方向；也可以改成较新的一侧覆盖。

## 包含 / 排除规则

任务选项里的「包含」「排除」决定哪些文件参与同步。规则写在文本框里，**多条用分号 `;`、竖线 `|` 或换行分开**。匹配**不区分大小写**。路径分隔符用 `/`（写 `\` 也会当成 `/`）。

判定顺序（对每个相对路径）：

1. 落在 `.sidesync-recycle` 下 → 始终排除（不写规则也会排除）
2. 命中任意一条**排除** → 排除（分析后在「全部」里标成已过滤）
3. **包含**为空 → 其余都参与
4. **包含**非空 → 必须再命中至少一条包含，才参与

右键菜单写入的规则与手写相同，例如「排除所有 xxx 文件夹」会写入 `xxx/`。

默认排除：`*.tmp`、`Thumbs.db`、`desktop.ini`。

### 规则长什么样

| 写法 | 含义 |
|------|------|
| `名字` 或 `*/名字` | 按**路径最后一段**匹配（任意深度的同名文件或文件夹） |
| `/相对路径` | 相对同步根的**整条路径**（只这一条树枝） |
| 含 `/` 但不以 `/` 开头 | 也按整条相对路径匹配，例如 `dir/only.csv` |
| 末尾 `/` | **只要文件夹**，并带上该文件夹下整棵子树 |
| 末尾 `:` | **只要文件**，不匹配同名文件夹及其内容 |
| `*` / `?` | 通配：任意串 / 单个字符（用在名字段时不跨目录） |
| `#` 开头 | 注释，忽略 |

### 举例

| 规则 | 含义 |
|------|------|
| `*.tmp;Thumbs.db;node_modules/` | 排除临时文件、缩略图，以及所有 `node_modules` 目录树 |
| `*.rs;*.toml`（包含）+ `target/`（排除） | 只要 Rust 源文件和清单，不要 `target` |
| `/src/main.rs` | 只匹配同步根下这一条路径 |
| `readme:` | 只要名叫 `readme` 的文件，不要同名文件夹 |
